# RobotExpressive

Source: three.js examples, `examples/models/gltf/RobotExpressive/RobotExpressive.glb`
(https://github.com/mrdoob/three.js). The GLB file is included unmodified.

* Model by Tomás Laulhé (Quaternius, https://quaternius.com) — Creative Commons Zero v1.0 Universal (CC0 1.0).
  Consider supporting the creator.
* Modifications by Don McCurdy: added the Angry / Surprised / Sad facial morph targets, converted
  with FBX2GLTF, removed duplicate materials and reduced material metalness.

License text: https://creativecommons.org/publicdomain/zero/1.0/legalcode

FocusBuddy uses this artist-made asset as the reference for validating skeletal clips, rigid
(bone-parented) meshes, root motion policies and morph-target faces. The bone / clip / morph
mapping is in `metadata.json` (FocusBuddy's own file).
